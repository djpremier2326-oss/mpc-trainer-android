# MPC Trainer — базовые приёмы MPC Live III

Учебное Android-приложение: импорт WAV/MP3 → назначение на пэды → запись двухтактовой Sequence → Overdub → Timing Correct → баланс → сохранение текущего проекта. Уроки на русском объясняют смысл действий и дают звуковые примеры.

## Что работает

- 16 пэдов в аппаратном порядке: 1–4 снизу, 13–16 сверху; банки A–D.
- REC → PLAY, отменяемый четырёхдольный Count In, STOP/продолжение и PLAY START.
- Overdub, многопэдовый Note Repeat, метроном, темп 40–240 BPM.
- TC 1/4…1/64, триоли, Swing, Shift Timing и DO IT для текущего трека.
- 16 Levels Velocity/Tune, запись высоты Tune, Pitch ±12 полутонов, PAD/MASTER volume.
- Четыре трека, Track Mute, двухстраничный Step Sequencer 1/16.
- Sample Edit: волна, Start/End, предпрослушивание и равномерная нарезка. Перезапись назначений подтверждается; исходный файл сохраняется.
- Undo/Redo для нот Sequence: проход REC/Overdub, шаги и TC. История текущего сеанса хранит до 32 операций.
- Текущий проект автоматически сохраняется; SAVE сохраняет его явно. При возврате приложение остаётся остановленным и помнит позицию. NEW PROJECT не возвращает старые данные при пересоздании Activity.

MENU содержит учебный набор звуков, PLAY START, UNDO/REDO, справочник и сброс проекта. Учебный набор занимает только свободные пэды.

## Границы тренажёра

Это учебное подмножество, не полный эмулятор MPC. Нет датчиков силы удара, aftertouch, полной структуры MPC 3 drum/keygroup/audio tracks, банков E–H, нескольких секвенций/проектов, Arrangement, MIDI/USB-синхронизации и экспорта XPJ. Обычное касание имеет фиксированную Velocity; динамику можно слышать через 16 Levels. Timing Android не равен аппаратному sample-accurate timing. Эффектов-пустышек в интерфейсе нет.

[Аудит, проверки и статус сверки с руководством](docs/manual-audit.md).

Звук: до 32 одновременных голосов, до 64 МБ декодированного PCM на сэмпл и до 128 МБ загруженного PCM в наборе. Слишком большой или неподдерживаемый файл отклоняется с сообщением, а не обрезается молча.

## Сборка и тестирование

Java 17, Android SDK 35, Gradle 8.9, Linux/macOS:

```sh
base64 --decode signing/training-debug.keystore.b64 > training-debug.keystore
gradle --no-daemon --max-workers=4 :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`, package `com.bytbeat.mpctrainer.learning`. Подпись совместима с предыдущей учебной версией. Ежедневник — другое приложение (`com.bytbeat.dayplan`), его файлы и данные не меняются.

Исходники Kotlin теперь являются единственным исходным кодом сборки. Скрипты `scripts/integrate_*.py` и `scripts/bridge_*.py` остались как история старых преобразований; перед сборкой их запускать нельзя. CI собирает и тестирует Kotlin напрямую, без цепочки текстовых подстановок.
