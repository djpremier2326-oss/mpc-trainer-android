# Календарь дел — отдельная версия ежедневника

Это отдельное Android-приложение, созданное **на основе** ветки `daily-planner-android`. Исходная ветка не изменялась.

- Исходное приложение: `com.bytbeat.dayplan`
- Новое приложение: `com.bytbeat.dayplan.calendar`
- Исходная ветка: `daily-planner-android`
- Ветка календаря: `calendar-first-planner`

## Первая версия

Главная — календарь месяца. В ячейках показаны короткие подписи напоминаний и задач, маркеры тренировок, фотографий и отмеченных взносов. Клик по дате открывает подробный просмотр и кнопки для полного расписания, цвета дня, события, фото, тренировок и накоплений.

Рабочие смены: «2 через 2», «день / ночь / два выходных», «5 через 2», «сутки / три выходных», отключение. Начало цикла задаётся произвольной датой. Ручная раскраска дней имеет приоритет перед цветами смен.

Фотографии прикрепляются к конкретным датам; хранятся локально в IndexedDB. Сохранение JSON-копии включает фотографии и избранное. Размер копии ограничен. Записи тренировок берутся из существующей истории упражнений, накопления — из существующего счётчика. Для новых оплаченных взносов записывается выбранная дата.

Все существовавшие разделы: подробный день, неделя, заметки с калькулятором и календарём, накопления, избранное, напоминания и темы — сохранены в коде.

## Данные и установка

Оба APK могут устанавливаться одновременно: разные `applicationId`. Данные **не переносятся автоматически**, поскольку у приложений разное изолированное хранилище. Для переноса в старом приложении выбрать «Настройки → Сохранить копию», затем в новом «Настройки → Загрузить копию».

## Сборка

GitHub Actions: `.github/workflows/android.yml` в ветке `calendar-first-planner`. Основной артефакт называется `raspisanie-apk` и содержит APK новой версии с именем `raspisanie.apk`. Исходный файл и оригинальная ветка остаются без изменений.

Техническая реализация нового экрана изолирована в `app/src/main/assets/calendar-first/`, чтобы в дальнейшем не ломать существующие модули. Это стартовая версия: интерфейс и сценарии нужно проверять на реальном телефоне.
