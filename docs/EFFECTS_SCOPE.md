# MPC TRAINER — Effects scope

The trainer will include exactly two learning effects after the core MPC workflow is stable:

1. COMPRESSOR
   - ON/OFF
   - Threshold
   - Ratio
   - Attack
   - Release
   - Makeup Gain
   - Gain Reduction meter
   - beginner presets: DRUMS / PUNCH / GLUE

2. EQ
   - simple educational EQ only
   - low / mid / high controls
   - ON/OFF
   - clear before/after audition

Rules:
- Effects must process audio for real; no decorative controls.
- Keep the UI compact and suitable for a phone.
- Do not add reverb, delay, saturation, limiter, or a large FX rack.
- Effects are secondary to the core MPC trainer and Learn Mode.
- Learn Mode should explain what each control changes and include an audible A/B task.
